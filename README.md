# Shunya

Minimalist, reproducible, hardware-aware Arch Linux desktop environment/distribution layer.

## Status

Shunya is a hobby/experimental project under active development.

## Goals

- Reproducibility
- Hardware awareness
- Minimalism
- Mindful dependencies
- Open source first
- Uniform design
- Deliberate complexity
- Recoverability
- No silent deviation
- Product mindset

## Scope

Shunya aims to provide a structured layer on top of a supported Arch Linux installation.

Long-term commands:

- `shunya install`
- `shunya update`
- `shunya doctor`
- `shunya reset`
- `shunya version`

## Disclaimer

Shunya is provided as-is and is used at the user's own risk.

It may modify system configuration, install software, change services, or otherwise affect an Arch Linux installation. Users should maintain appropriate backups and review changes before execution.

Hardware compatibility may vary.

Shunya is a hobby/experimental project and does not guarantee production-grade reliability or universal hardware compatibility.
